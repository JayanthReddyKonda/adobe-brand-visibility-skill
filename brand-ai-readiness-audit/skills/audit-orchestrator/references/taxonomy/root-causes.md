# Unified Root-Cause Taxonomy for AI Brand Visibility

This document establishes the canonical root-cause classification used across all specialists in the Brand AI-Readiness Audit Marketplace.

---

## Taxonomy Structure

Every finding generated by a specialist or composed by the orchestrator must map to one of the following five **Root Cause Families**:

```text
AUDIT TAXONOMY
│
├── DISCOVERY.ACCESS / DISCOVERY.RENDERING / DISCOVERY.CANONICAL
│   └── Failures preventing AI search crawlers from fetching, executing, or indexing content.
│
├── ENTITY.IDENTITY / ENTITY.ANSWERABILITY
│   └── Failures preventing AI models from understanding who the brand is or extracting core facts.
│
├── FACT.CONSISTENCY / FACT.FRESHNESS
│   └── Failures caused by contradictory, outdated, or drifting factual assertions on first-party pages.
│
├── AUTHORITY.CORROBORATION
│   └── Failures where declared external identity anchors (sameAs) are broken or conflicting.
│
├── EXPERIENCE.CONTINUITY
│   └── Failures where visitors referred by AI search encounter low-scent or discontinuous landing pages.
│
└── REPRESENTATION.ACCURACY
    └── Discrepancies between observed AI assistant outputs and verified first-party facts.
```

---

## Detailed Root Cause Matrix

| Cause Family | Cause ID | Mechanism Summary | Default Severity |
| :--- | :--- | :--- | :--- |
| `DISCOVERY.ACCESS` | `DISC-ROBOTS-RETRIEVAL-BLOCKED` | robots.txt blocks AI search retrieval crawlers (e.g. `OAI-SearchBot`, `PerplexityBot`). | `critical` / `high` |
| `DISCOVERY.ACCESS` | `DISC-NOINDEX` | robots meta tag or X-Robots-Tag header excludes page from indexing. | `critical` |
| `DISCOVERY.ACCESS` | `DISC-HTTP-ERR` | Core page returns 4xx/5xx HTTP error. | `critical` |
| `DISCOVERY.ACCESS` | `DISC-WAF-BLOCK` | Edge WAF or firewall selectively blocks AI crawler User-Agents. | `high` |
| `DISCOVERY.RENDERING` | `DISC-CSR-RENDERING-RISK` | Core text missing from initial HTML response (SPA client-side rendering dependency). | `high` |
| `DISCOVERY.CANONICAL` | `DISC-CANONICAL-MISMATCH` | Canonical tag consolidates onto a different un-audited host. | `medium` |
| `ENTITY.IDENTITY` | `ENT-ORG-IDENTITY-MISSING` | No machine-explicit Organization/Brand identity in JSON-LD or OpenGraph. | `medium` |
| `ENTITY.ANSWERABILITY` | `ENT-PRODUCT-FIELDS-INCOMPLETE` | Product/Offer schema omits material commercial fields (price, availability). | `low` |
| `ENTITY.ANSWERABILITY` | `ENT-ANSWERABILITY-GAP` | Page type missing core factual attributes expected for user query answerability. | `low` / `recommendation` |
| `FACT.CONSISTENCY` | `FACT-PRICE-CONTRADICTION` | Same product or plan published with conflicting prices across pages. | `high` |
| `FACT.FRESHNESS` | `FACT-COPYRIGHT-DISPARITY` | Disparate copyright years across pages signal stale footer maintenance. | `medium` |
| `FACT.FRESHNESS` | `FACT-TIMESTAMPS-MISSING` | Absence of ISO 8601 modification timestamps on content pages. | `low` |
| `AUTHORITY.CORROBORATION` | `AUTH-SAMEAS-BROKEN` | Declared sameAs profile URL returns 4xx/5xx HTTP error. | `medium` |
| `EXPERIENCE.CONTINUITY` | `ENG-H1-MISSING` | Content page omits primary `<h1>` topic statement. | `medium` |
| `EXPERIENCE.CONTINUITY` | `ENG-H1-GENERIC` | Primary H1 uses generic filler words ("Welcome", "Home") lacking information scent. | `low` |
| `EXPERIENCE.CONTINUITY` | `ENG-NAV-ABSENT` | Page lacks navigation links to core brand destinations (Pricing, Docs, Contact). | `medium` |
| `REPRESENTATION.ACCURACY` | `REP-PRICE-CONFLICT` | Observed AI assistant quotes pricing that contradicts on-site facts. | `high` |
| `REPRESENTATION.ACCURACY` | `REP-UNSUPPORTED-CLAIM` | Observed AI assistant makes ungrounded claims about brand capabilities. | `medium` |
